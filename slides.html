Problem & context

Keeping up with research doesn't scale

  • arXiv publishes thousands of papers per week; a single field (e.g. NLP) gets hundreds of new pre-prints every month.
  • Researchers, R&D teams, analysts and newcomers need to know what's trending — and what matters to them — without reading everything.
  • Manual literature review is slow, subjective, and always out of date.

Business relevance: competitive intelligence, R&D prioritisation, onboarding new team members, staying current.

Real data, live, no paid keys

Methods used

Standard NLP techniques, correctly applied

Keyword extraction

  • TF-IDF (unigrams + bigrams) → the trending vocabulary.

Topic discovery (text classification)

  • KMeans + BERTopic (selectable) → sub-topics; CV interests mapped to arXiv categories.

Entity extraction

  • Rule-based method/model acronyms + spaCy NER for named concepts.

Summarisation

  • distilBART (Hugging Face) → automatic trend overview.

We deliberately replaced sentiment (meaningless for research abstracts) with topic discovery — what trend analysis actually needs.

Optional LLM component

The personal newsletter: an agentic pipeline

A local instruction-tuned LLM (Qwen2.5-Instruct) — no API key.

CV → name + interests→ plan queries→ fetch→ cluster + select top 10→ summaries + preview→ quality-control critique
  • Interests → short arXiv search keywords + categories.
  • A bounded self-correction loop retries if quality checks fail; results are cached weekly.

Complements — does not replace — the deterministic pipeline.

Key results & interpretation

Turning hundreds of abstracts into insight

  • Term evolution (cs.CL): "llm" 0% → 0% → ~50%" of papers (2013→2018→2023), "word" 42% → 8%, "neural" peaking in 2018 — the LLM era, visible in one chart.
  • Radar comparison (cs.LG, 1998 vs 2023): authors/paper 2.3 → 5.0, methods/paper 2.6 → 7.4 — the field maturing: more collaborative and method-dense.
  • Personalised digest: a top-10 curated from a real CV's interests, each with a one-line summary.

Limitations & improvements

Honest about scope

Limitations

  • General-purpose NER misses scientific entities; abstracts only.
  • Small local LLM (0.5B) — occasional weak JSON / summaries.
  • arXiv rate limits; KMeans needs k; BERTopic needs many papers.

Improvements

  • Scientific NER (SciSpaCy / SciERC); larger LLM (Qwen 1.5B+).
  • Trend-over-time; citation signals; email delivery.
  • Cloud deploy with cached models.
