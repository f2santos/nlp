arXiv Trend Radar1
Problem & context

Staying on top of a fast-moving field is impossible by hand

  • arXiv publishes thousands of papers per week; a single subject (e.g. NLP) gets hundreds of new pre-prints every month.
  • Researchers, R&D teams, analysts and investors need to know what's trending — which methods and sub-topics are heating up — without reading it all.
  • Manual literature review is slow, subjective, and always out of date.

Business angle: competitive intelligence, R&D prioritisation, keeping a team current.

arXiv Trend Radar2
Why NLP

This is a text-understanding problem at scale

  • The signal lives in unstructured text — titles and abstracts.
  • NLP lets us extract, group and summarise that text automatically: keywords, sub-topics, entities, and a readable summary.
  • Turns hundreds of abstracts into one interpretable trend report.
arXiv Trend Radar3
Data source

Real data from the arXiv API

Public, live, no API key

  • Public arXiv Atom API — export.arxiv.org/api/query.
  • Fetches the latest papers in a chosen category, sorted by submission date.
  • 17 subjects selectable (cs.AI, cs.CL, cs.LG, cs.CV, quant-ph, q-bio, …), with optional keyword refinement.
  • Per paper: title, abstract, authors, date, categories, links.
arXiv Trend Radar4
Pipeline overview

A simple, complete, interpretable pipeline

arXiv API→ clean→ keywords→ topic discovery→ NER→ summary→ report
  • Each stage is small and explainable.
  • Heavy models are cached; everything runs on free, open tools.

"Simplicity over complexity — a well-executed simple pipeline."

arXiv Trend Radar5
Methods

Standard NLP techniques, correctly applied

Keyword extraction

  • TF-IDF (unigrams + bigrams) → the trending vocabulary.

Topic discovery

  • TF-IDF + KMeans clustering → sub-topics (unsupervised text classification).

Named-entity recognition

  • spaCy → organisations, people, places, systems.

Preprocessing

  • Cleaning + domain stopwords to remove academic boilerplate.

We deliberately replaced sentiment with topic discovery — sentiment is meaningless for research abstracts; sub-topics are what trend analysis needs.

arXiv Trend Radar6
Optional LLM component

Automatic summary with a local language model

  • distilBART (Hugging Face) summarises the latest abstracts into a short "what the field is working on" paragraph.
  • Runs locally, no API key, free to deploy.
  • Complements the pipeline — it does not replace it.

arXiv Trend Radar8
Limitations & improvements

Honest about scope

Limitations

  • General-purpose NER (misses scientific entities).
  • Abstracts only — no full text.
  • KMeans needs a chosen k; English-only summariser.

Improvements

  • Scientific NER (SciSpaCy); topic modelling (BERTopic/LDA).
  • Trend-over-time across months; citation signals.
  • Optional LLM-API report for richer interpretation.
